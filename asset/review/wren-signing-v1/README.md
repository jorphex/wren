# Wren signing review

`transaction-review.html` is a code-native 760 × 900 proof for the signing-critical transaction
surface. It uses the production Wren tokens, corrected hybrid typography, functional line glyphs,
ruled detail rows, and quiet-tactile controls. It intentionally contains no illustrative artwork.

The direction replaces nested Frame cards and animated split pills with one continuous review canvas,
explicit evidence, and a fixed signer/action shelf.

`02-transaction-review-corrected.png` is the current reviewed-size headless capture. It supersedes the
initial layout proof by making sender and recipient identities direct copy targets, exposing nonce and
fee editing, naming the contract-data disclosure, and giving Decline and Sign transaction identical
geometry. The continuous sections, compact pre-sign shelf, tactile controls, and flat required-approval
treatment are integrated in production styles; submitted transaction monitoring retains its independent
status height and behavior.

`typed-data-review.html` extends the same production-sized language to a high-risk EIP-712 Permit2
allowance. Its corresponding `03-typed-data-review.png` is the approved review proof; the sparse hierarchy,
neutral structure-recognition language, authority summary, exact-data disclosure, and signer shelf are
integrated into production message-signing surfaces.

The superseded first transaction proof was removed; only the corrected capture and reproducible source
remain.
