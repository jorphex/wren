# Wren design review archive

This directory keeps selected design evidence and the source needed to reproduce it. Rejected,
superseded, layout-only, and intermediate single-purpose plates are removed after their decision is
captured in the surviving README or working notes.

## Authority

Read `DESIGN.md`, `IMAGE_GEN.md`, and `NOTES.md` before using this archive. Then read the nearest
directory README and inspect both its current capture and source. A directory name does not itself mean
every concept in a comparison image was selected.

pruned after selection so this archive remains usable as design memory rather than another transcript.
