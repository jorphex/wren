# Wren design review archive

**Purpose:** selected design evidence and the source required to reproduce it.

**Status:** this is a decision archive, not a runtime dependency. Directory names identify a review,
not a blanket approval of every option shown in its captures.

**Archive rules:** each child README names its selected direction and labels retained material as
selected, evidence-only, or layout-only. Rejected, superseded, and intermediate plates are removed
once their durable decision is recorded.

## Authority

Read `DESIGN.md`, `IMAGE_GEN.md`, and `NOTES.md`, then the child README and its retained capture and
source.
