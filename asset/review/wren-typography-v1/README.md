# Wren typography plate — review v1

**Purpose:** compare typography roles at Wren's 760 × 900 shell size.

**Status — selected and integrated:** Sharper Recursive, later refined to the corrected hybrid:
Recursive for headings, prose, row labels, and controls; Fira Code for addresses, numeric values, and
compact utility roles. Nothing here is a runtime dependency.

- **Evidence-only:** `01-type-hierarchy-directions.png` compares Current Wren, Sharper Recursive,
  Mono-forward names/titles, and a restricted true-pixel accent.
- **Source:** `typography-plate.html` reproduces the plate.

The Mono-forward and true-pixel directions were rejected. At Wren's working sizes, true-pixel counters
and apertures collapse and its kerning becomes uneven. Revisit pixel type only with a purpose-built
face and small-size optical masters.
