# Wren lightweight request family

Production-sized visual proof for Wren's account-access and add-token request screens.

- `01-account-access.png` — shares one public account while making later approval boundaries explicit.
- `03-add-token.png` — emphasizes contract identity before opening the token editor.
- `request-family.html` — shared source; select a screen with `?view=access` or `?view=token`.

The family uses the approved balanced dark tokens, corrected hybrid typography, Wren's optical icon
masters, sparse evidence sections, and the feather-gold tactile primary action. These lightweight
requests intentionally omit signing-device language because no signature is produced on these screens.
The separate add-network handoff was removed after the selected editor direction combined proposal and
editing into one decision.
