# Wren lightweight request family

**Purpose:** production-sized proof for account-access and add-token requests.

**Status — selected:** the lightweight request family; integrated with the approved token, type, icon,
and primary-action language.

- **Selected evidence:** `01-account-access.png` shares one public account and makes later approval
  boundaries explicit.
- **Selected evidence:** `03-add-token.png` establishes contract identity before the token editor.
- **Source:** `request-family.html`; use `?view=access` or `?view=token`.

These requests use sparse evidence sections and intentionally omit signing-device language: neither
screen produces a signature. The separate add-network handoff was superseded when the selected editor
combined proposal and editing into one decision.
