# Wren input-field plate — review v1

**Purpose:** compare input-field directions at Wren's 760 × 900 shell size.

**Status — selected and integrated:** **02 Chiseled well** for normal form fields; **01 Quiet inset**
for search and filters. This directory is a review reference, not a runtime dependency.

- **Evidence-only:** `01-input-field-directions.png` compares four levels of game-menu influence with
  real field content, focus and validation treatment, and the UI/technical type split.
- **Source:** `input-field-plate.html` reproduces the plate.

Chiseled well borrows the dark inset well and crisp rim of Minecraft menu inputs without copying its
font, scale, or heavy gray framing. Other directions were rejected.
