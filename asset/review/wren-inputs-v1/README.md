# Wren input-field plate — review v1

Input-field directions at Wren's 760 × 900 shell size. The Chiseled well treatment is now integrated
for normal form fields, with Quiet inset retained for search and filter fields; this directory remains
a review reference rather than a runtime dependency.

- `01-input-field-directions.png` — four curated levels of game-menu influence, shown with real Wren
  field content, focus treatment, validation treatment, and the UI-versus-technical type split.
- `input-field-plate.html` — self-contained source for the plate.

The selected direction is **02 Chiseled well**, softened toward **01 Quiet inset** for search fields.
It borrows the dark inset well and crisp rim of Minecraft menu inputs without copying its font,
scale, or heavy gray framing.
