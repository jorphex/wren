# Wren selected control language

HTML/CSS design studies at Wren's current 760 × 900 shell size. The account header, flat switcher
drawer, right-aligned Add account action, and private-balance behavior from the latest study are now
integrated; these files remain review references rather than runtime dependencies.

- `01-quiet-tactile.png` and `preview.html` — selected rounded geometry, matte fills, crisp inner
  highlight, and one-pixel pressed edge.
- `09-pixel-token-round-v5.png` and `pixel-icon-v2.html` — selected light pixel-authored family with
  separate 20px and simplified 16px optical masters and the corrected round token.
- `16-account-home-ui.png` — actual visual-language study of the dismissed account home: tactile
  controls, production pixel glyphs, decorative-symbol placements, private holdings, and populated
  content density.
- `17-account-drawer-ui.png` — matching actual-UI state with the border-light account drawer open.
- `account-drawer-preview.html` — self-contained source for the drawer and private-balance study.

Rejected, superseded, layout-only, and intermediate comparison plates were removed after selection.
The retained sources reproduce only the durable directions needed for future comparison.
