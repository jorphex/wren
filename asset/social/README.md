# Wren social artwork

The profile and X header use the **Night Rounds** direction. The profile keeps
Wren's canonical full-color character on the product's dark textured canvas;
the header is a purpose-built 3:1 pixel-art garden panorama. Neither uses an
app-icon tile, wordmark, or marketing copy. This keeps the avatar clear under a
circular crop and lets the wider surface add atmosphere instead of repeating
the profile mark.

Generated outputs:

- `wren-profile-400.png` — 400 × 400 profile image. The entire character stays
  inside a centered 320 px safe circle.
- `wren-x-header-1500x500.png` — 1500 × 500 X header generated from
  `source/wren-night-rounds-v1.png`. The gate lantern balances the left, the
  path connects the panorama, and the detailed wren and main lantern anchor the
  right. Essential focal content remains legible if X removes the outer 60 px
  at the top and bottom.

Both files are generated by `npm run brand:generate`; the profile uses
`asset/brand/wren-mark.svg` and `resources/svg/wren-grain.svg`, while the header
uses the generated Night Rounds master above. Do not edit the delivery PNGs
directly. Current platform dimensions and cropping guidance are documented by
X at <https://help.x.com/en/managing-your-account/common-issues-when-uploading-profile-photo>.

The Night Rounds master was generated with the built-in image-generation tool
using `asset/ui/onboarding-welcome.png` as the visual reference. Its production
brief specified a native 3:1 nocturnal garden panorama with an open gate and
secondary lantern on the left, a winding path and distant lantern in the
middle, and one detailed wren beside the main lantern on the right. It excluded
text, logos, crypto imagery, UI panels, and fantasy effects.
