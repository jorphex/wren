# Wren 0.1.7

Wren 0.1.7 makes transaction review steadier on busy or partially compatible
RPCs and fixes allowance editing.

## Transaction review

- Background fee updates no longer bounce a request between final checks and
  ready for review. A new quote is applied only after its execution check completes.
- Valid transaction quantities are normalized before RPC use, including values
  returned with leading zeroes.
- Funding rechecks refresh gas and fee evidence for the request being retried.
  Failures remain recoverable and use short messages without raw RPC responses.
- A failed background refresh no longer replaces a usable review result.

## Token approvals

- Requested, custom, unlimited, and revoke allowance changes keep the approval
  editor open while simulation and action recognition refresh.
- The selected allowance appears immediately, including unlimited and zero.
- Production interaction coverage now exercises transaction and permit amount
  changes through live-style state updates.

## Distribution

- Linux x64: `Wren-0.1.7.AppImage` and `wren_0.1.7_amd64.deb`.
- Windows x64 preview: `Wren-Setup-0.1.7-unsigned-x64.exe`.
- macOS previews: `Wren-0.1.7-macos-x64-unnotarized.dmg` and
  `Wren-0.1.7-macos-arm64-unnotarized.dmg`.

Verify the selected file against `SHA256SUMS` and its GitHub attestation. Linux
x64 remains the qualified target. Windows is unsigned and unqualified. macOS is
ad-hoc signed, unnotarized, and unqualified pending checks on the exact physical
hardware. Wren has not had an independent security audit; keep a backup and
start with a small test account.
