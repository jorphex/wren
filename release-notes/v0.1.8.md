# Wren 0.1.8

Wren 0.1.8 makes the wallet easier to scan and navigate, with shorter copy,
clearer transaction states, and more consistent spacing across full and compact
windows.

## Wallet and navigation

- Receive opens an inline QR popover with the full address and Copy action,
  keeping the wallet visible behind a blurred backdrop.
- Portfolio totals distinguish known value, missing prices, unavailable balances,
  and loading states instead of presenting incomplete data as a complete total.
- Settings are grouped into General, Privacy, Connections, Security, and Advanced.
- Onboarding goes directly to account setup, and Connected apps links directly
  to the accounts whose access you can manage.
- Account setup, contacts, token entry, and network editing use clearer labels
  and more consistent alignment. Contact and network actions stay reachable
  while their forms scroll.

## Sending and transaction review

- Send separates the source account from the asset selector. Recipient details
  have room to breathe, and compact windows keep the fee row above Review send.
- Send progress distinguishes awaiting review, waiting for the signer,
  submission, confirmation, and an unconfirmed broadcast.
- Transaction action areas share a consistent minimum height. Recovery messages,
  lifecycle facts, and buttons stay aligned; Sweep review scrolls above its actions.
- Funding summaries show readable amounts with an approximation marker where
  needed. Exact amounts replaces the values in the same rows without enlarging
  the footer into a second review panel.
- Approval, signing, contract, and inspector screens put the immediate decision
  first while retaining technical details for inspection.

## Earn and app access

- Earn uses aligned vault metadata, plain token logos, grouped external links,
  and positions that are always visible.
- During an active cooldown, Cancel cooldown and Deposit remain visible. Deposit
  opens its amount form when selected.
- Guardrail connection identity stays visible in a compact label/value layout.
  Permission details and actions follow consistent margins.

## Verification

Expanded component and native-renderer regression coverage checks compact and
scaled layouts, footer placement, field alignment, recipient spacing, cooldown
controls, and exact-value privacy behavior. These automated checks do not replace
physical-device or platform qualification.

## Distribution

- Linux x64: `Wren-0.1.8.AppImage` and `wren_0.1.8_amd64.deb`.
- Windows x64 preview: `Wren-Setup-0.1.8-unsigned-x64.exe`.
- macOS previews: `Wren-0.1.8-macos-x64-unnotarized.dmg` and
  `Wren-0.1.8-macos-arm64-unnotarized.dmg`.

Verify the selected file against `SHA256SUMS` and its GitHub attestation. Linux
x64 remains the qualified target. Windows is unsigned and unqualified. macOS is
ad-hoc signed, unnotarized, and unqualified. The 0.1.8 Windows and macOS previews
have not been physically installed or qualified as part of this release
preparation. Wren Companion 0.1.2 continues to pair over authenticated protocol 3.
Wren has not had an independent security audit; keep a backup and start with a
small test account.
