# Wren 0.1.8

Wren 0.1.8 uses shorter text, clearer transaction states, and consistent spacing.
These changes make full and compact windows easier to read and use.

## Wallet and navigation

- Receive opens a QR popover with the full address and Copy action.
  The wallet stays visible behind a blurred background.
- Portfolio totals show when prices or balances are missing or still loading.
  Wren does not show a partial value as a complete total.
- Settings are grouped into General, Privacy, Connections, Security, and Advanced.
- First launch opens account setup. Connected apps links to the accounts
  where you can manage access.
- Account setup, contacts, token entry, and network editing use clearer labels
  and more consistent alignment. Contact and network actions stay reachable
  while their forms scroll.

## Sending and transaction review

- Send has separate account and asset fields. Recipient details have more space.
  Compact windows keep the fee row above Review send.
- Send progress distinguishes awaiting review, waiting for the signer,
  submission, confirmation, and an unconfirmed broadcast.
- Transaction action areas have the same minimum height. Status, recovery
  messages, and buttons stay aligned. Sweep review scrolls above its actions.
- Funding summaries mark rounded amounts as approximate. Select Exact amounts
  to show precise values in the same rows. The action area keeps its size.
- Approval, signing, contract, and inspector screens show the main decision
  first. Technical details remain available.

## Earn and app access

- Earn aligns vault details, removes logo rings, and groups external links.
  Your position stays visible.
- During an active cooldown, Cancel cooldown and Deposit remain visible. Deposit
  opens its amount form when selected.
- Guardrails keep connection details visible. Permission details and actions
  use consistent margins.

## Verification

Tests now cover compact and scaled windows, action areas, field alignment,
recipient spacing, cooldown controls, and privacy for exact amounts.
Automated tests do not replace checks on physical devices or each platform.

## Distribution

- Linux x64: `Wren-0.1.8.AppImage` and `wren_0.1.8_amd64.deb`.
- Windows x64 preview: `Wren-Setup-0.1.8-unsigned-x64.exe`.
- macOS previews: `Wren-0.1.8-macos-x64-unnotarized.dmg` and
  `Wren-0.1.8-macos-arm64-unnotarized.dmg`.

Verify the selected file against `SHA256SUMS` and its GitHub attestation. Linux
x64 remains the qualified target. Windows is unsigned and unqualified. macOS is
ad-hoc signed, unnotarized, and unqualified.

This release preparation did not include physical installation or qualification
of the 0.1.8 Windows and macOS previews. Wren Companion 0.1.2 continues to pair
over authenticated protocol 3.

Wren has not had an independent security audit. Keep a backup and start with a
small test account.
