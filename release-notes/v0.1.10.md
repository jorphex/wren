# Wren 0.1.10

Wren 0.1.10 adds external account activity and direct installation links for Firefox Companion.

## Account activity

- Track direct transactions and standard token transfers across saved addresses on enabled, connected networks.
- Recognise common approvals, deposits, and withdrawals. Activity submitted elsewhere shows **Outside Wren**.
- Receive private alerts while Wren is hidden. Alerts omit amounts and addresses.
- Resume scanning after reconnects and restarts, with duplicate checks and reorg recovery.

Monitoring starts at the current chain position and runs while Wren is open. Earlier history and internal-call traces are outside this version.

## Browser companion

Install [Wren Companion for Firefox](https://addons.mozilla.org/en-US/firefox/addon/wren-companion/) directly from Control Center or onboarding. Companion 0.1.2 continues to use paired protocol 3.

## Maintenance

Updated Electron, React, Ledger libraries, validation, and development tools. React and React DOM now update together.

## Downloads

- Linux x64: `Wren-0.1.10.AppImage` and `wren_0.1.10_amd64.deb`.
- Windows x64 preview: `Wren-Setup-0.1.10-unsigned-x64.exe`.
- macOS previews: `Wren-0.1.10-macos-x64-unnotarized.dmg` and `Wren-0.1.10-macos-arm64-unnotarized.dmg`.

Check downloads against `SHA256SUMS` and their GitHub attestations. Linux x64 remains the qualified target. Windows and macOS previews were not physically installed or qualified for this release. Windows is unsigned; macOS is ad-hoc signed and unnotarized. macOS device protection remains unsupported.
