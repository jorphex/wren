# Wren 0.1.3

This desktop follow-up refines dapp account-access review and pairs with Wren
Companion 0.1.2.

- Account-access review now uses compact, accessible Decline and Allow access
  controls at both normal and short tray heights.
- Lightweight request footers share the intended action/context layout instead
  of inheriting the oversized legacy split-button positioning.
- Copyable public-account evidence retains a 44-pixel interaction target.

Browser connection compatibility, tab-status aggregation, and transient network
catalog recovery are delivered by Wren Companion 0.1.2. The authenticated local
protocol remains version 3.

Linux artifacts:

- `Wren-0.1.3.AppImage`
- `wren_0.1.3_amd64.deb`
