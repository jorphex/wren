# Wren 0.1.11

Wren 0.1.11 improves startup, wallet recovery, and signing. It also updates Trezor USB support.

## Changes

- Fixed startup when saved RPC latency is invalid. Wallet and network settings stay intact.
- Added recovery for failed or unresponsive wallet views.
- Set time limits for transaction checks. Cancelled requests ignore late replies.
- Prevented repeat Sign clicks during signer checks. Submitting shows when sending begins.
- Used an enabled network for new site connections.
- Updated Trezor USB support to Connect 10. Existing accounts and signing features stay the same.
- Matched Trezor PIN, passphrase, and pairing replies to their active prompts.
- Updated Electron, Axios, Ledger libraries, and development tools.

Companion 0.1.3 adds browser connection retry fixes and needs a separate extension update.
Companion 0.1.2 remains compatible with Wren 0.1.11.

## Testing

Safe 7 signing, cancellation, and USB reconnect passed user testing on Linux.
Model One was also user-tested with Connect 10. See [signer support](../HARDWARE_SUPPORT.md).

This release was built from `18561d23`. The quality gate and all platform package jobs
passed in the [release build](https://github.com/jorphex/wren/actions/runs/36840460713).

Check downloads against `SHA256SUMS` and their GitHub attestations.
Linux x64 is the main release target. Windows and macOS are previews without physical
installation tests for this release. Windows is unsigned; macOS is ad-hoc signed
and unnotarized. macOS device protection is not supported.
