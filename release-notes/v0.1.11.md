# Wren 0.1.11

Wren 0.1.11 fixes startup failures caused by invalid saved RPC latency measurements.

## Startup reliability

- Discard cached RPC latency before validating the saved profile, preserving wallet and network configuration.
- Measure connection latency with a monotonic clock so system clock changes cannot produce negative durations.

## Maintenance

Patched transitive dependencies through the existing security overrides. Removed redundant tests while retaining behavioral regression coverage.
