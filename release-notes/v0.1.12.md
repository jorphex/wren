# Wren 0.1.12

Wren 0.1.12 fixes startup failures caused by invalid saved RPC latency measurements.

## Startup reliability

- Discard cached RPC latency before validating the saved profile, preserving wallet and network configuration.
- Measure connection latency with a monotonic clock so system clock changes cannot produce negative durations.

## Maintenance

Updated Electron to 42.11.8 with upstream Chromium/V8 and graphics-engine fixes, including use-after-free and renderer validation fixes. Patched transitive dependencies through the existing security overrides. Removed redundant tests while retaining behavioral regression coverage.
