# Wren 0.1.12

Wren 0.1.12 adds token approval management and clearer signing reviews.
It also improves balance reads, hardware wallet support and layout.

## Changes

- Added an account **Approvals** list to check allowances and review revocations.
  It includes ERC-20 approvals observed by Wren and Activity.
- Simplified signing reviews. Kept account, fee and actions together, with raw
  data and advanced controls available.
- Showed spender contract names and readable token amounts when metadata is available.
  Added token-event previews from supported RPC traces.
- Required new token-access consent when the reviewed request changes.
  Detected unlimited token and NFT operator approvals in batches.
- Fixed Lattice transaction requests and added support for Hyperliquid agent-approval messages.
- Improved balance reads on networks with RPC limits. Preserved token edits and
  custom metadata during background scans.
- Refined account setup, Earn, Settings and transaction spacing.
  Kept private-key creation visible.
- Fixed Trezor requests that could stay pending after closing the connection.
- Updated Electron, hardware wallet libraries and development tools.
  Removed unused code, assets and dependencies.

The Approvals list does not include earlier approvals, NFT approvals or signed permits.
Companion 0.1.2 and 0.1.3 remain compatible over pairing protocol 3.

installation tests for this release. Windows is unsigned; macOS is ad-hoc signed
and unnotarized. macOS device protection is not supported.
