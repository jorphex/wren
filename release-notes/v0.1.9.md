# Wren 0.1.9

Wren 0.1.9 adds prices for more tokens and a shortcut to set token allowances.
It also refines wallet navigation and Receive.

## Token approvals

- Approval and permit amount editors show **Your balance**. Select **Use balance**
  to set a custom allowance to that amount. Wren keeps the full token precision.
- The balance stays visible for Requested, Unlimited, and Custom. Wallet privacy
  hides the balance and disables the shortcut. If the balance cannot be read,
  select Retry.
- Amount options and the balance button use tactile controls. The selected
  amount option stays pressed in.

## Token prices

- GeckoTerminal supplies token prices when DefiLlama has no quote. This includes
  custom tokens on Ethereum, Optimism, Gnosis, Polygon, Base, Arbitrum, and Katana.
- Prices come from the most liquid pool that meets the selection criteria. See
  [price sources](../README.md#privacy) for supported pools and refresh timing.
- Requests go directly from your desktop. Wren spaces them out and caches quotes.
  Wren sends token and network IDs, not your wallet address or balance.
- Primary price updates continue during pool searches. Token prices stay separate
  by network and contract. Send uses the correct USD quote.
- Quotes without price history do not show a percentage change. If a new quote
  is unavailable, Wren keeps the last known value, when present.

## Wallet and navigation

- Receive opens on click. Click outside to close it and return to the wallet.
- Control Center uses the original navigation rows without number counters.
- The portfolio balance has no status captions below it.

## Distribution

- Linux x64: `Wren-0.1.9.AppImage` and `wren_0.1.9_amd64.deb`.
- Windows x64 preview: `Wren-Setup-0.1.9-unsigned-x64.exe`.
- macOS previews: `Wren-0.1.9-macos-x64-unnotarized.dmg` and
  `Wren-0.1.9-macos-arm64-unnotarized.dmg`.

Check the downloaded file against `SHA256SUMS` and its GitHub attestation.
Linux x64 remains the qualified target. Windows is unsigned and unqualified.
macOS is ad-hoc signed, unnotarized, and unqualified. macOS device protection
is unsupported.

Release preparation does not include physical installation or qualification of
these Windows and macOS previews. Wren Companion 0.1.2 continues to use
paired protocol 3.
