# Wren 0.1.13

Wren 0.1.13 makes signing reviews easier to scan and helps you find tokens.
Trezor now connects through Trezor Suite Desktop.

## Changes

- See estimated asset changes together. Open **Advanced details** for each movement.
- Save a reviewed contract address to Contacts.
- Use **Find tokens** to check recent Activity or the bundled catalog. Choose which tokens to add.
- Wren checks that each signed transaction matches the approved request before sending it.
- Wren asks for confirmation before you turn off device protection or prepare a profile restore.
- Retry or reload the dashboard if it cannot open.
- Refined navigation, spacing, and scroll cues.

Companion 0.1.2 and 0.1.3 remain compatible.

## Trezor

Open Trezor Suite Desktop on the same computer. Review the request in Wren,
then continue in Suite. Your saved Trezor accounts stay in Wren.
See the [Trezor connection guide](https://github.com/jorphex/wren/blob/main/TREZOR_SUITE.md).

## Downloads

- Linux x64: AppImage and deb.
- Windows x64: unsigned preview installer.
- macOS Intel and Apple Silicon: unnotarized preview DMGs.

Check downloads against `SHA256SUMS` and their GitHub attestations.
See [signer and platform support](https://github.com/jorphex/wren/blob/main/HARDWARE_SUPPORT.md) for test coverage.
