# Wren 0.1.13

Wren 0.1.13 simplifies signing reviews and adds **Find tokens**.
Trezor now connects through Trezor Suite Desktop.

## Changes

- Grouped estimated asset changes. Kept each movement in **Advanced details**.
- Added a shortcut to save a reviewed contract address to Contacts.
- Added **Find tokens** to check recent activity and the token catalog. You choose which tokens to add.
- Wren checks the signed transaction against your approval before sending it.
- Asked for confirmation before turning off device protection or preparing a profile restore.
- Added **Try again** and **Reload dashboard** when the dashboard can't open.
- Moved Earn into the Control Center grid.
- Fixed Earn rates and removed Katana vaults. Use Yearn to manage existing Katana vault positions.
- Kept Earn actions visible in shorter windows. Hid the withdrawal form when you can't withdraw.
- Made selected options easier to see in Send, Settings, and approval reviews. Matched button feedback across the wallet.

Companion 0.1.2 and 0.1.3 remain compatible.

## Trezor

Open Trezor Suite Desktop on the same computer. Review the request in Wren,
then continue in Suite. Your saved Trezor accounts stay in Wren.
See the [Trezor connection guide](https://github.com/jorphex/wren/blob/main/TREZOR_SUITE.md).

## Testing

The Linux x64 candidate passed startup checks and a deb upgrade from 0.1.12.
The maintainer confirmed the rebuilt deb. Trezor Suite connection, signing,
and reconnect passed user testing on an earlier 0.1.13 build.

## Downloads

- Linux x64: `Wren-0.1.13.AppImage` and `wren_0.1.13_amd64.deb`.
- Windows x64 preview: `Wren-Setup-0.1.13-unsigned-x64.exe`.
- macOS previews: `Wren-0.1.13-macos-x64-unnotarized.dmg` and `Wren-0.1.13-macos-arm64-unnotarized.dmg`.

Check downloads against `SHA256SUMS` and their GitHub attestations.
Linux x64 is the main release target. Physical installation tests and qualification
are pending for Windows and macOS. Windows is unsigned. macOS is ad-hoc signed
and unnotarized. Device protection is unavailable on macOS. See
[signer and platform support](https://github.com/jorphex/wren/blob/main/HARDWARE_SUPPORT.md) for test coverage.
