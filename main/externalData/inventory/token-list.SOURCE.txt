Merge

Identity is chain ID plus lowercase contract address. All original entries,
metadata and exclusions remain. New entries use Uniswap metadata before Smol
metadata when both lists contain the same identity. Only EVM mainnet additions
are included; native-token sentinels and non-EVM entries are excluded.

Added 3,330 tokens: 1,579 from Uniswap and 1,751 additional tokens from Smol.
The merged catalog contains 9,622 unique identities. Incoming entries retain
only name, symbol, address, chain ID, decimals and an HTTPS/IPFS logo URI when
available.

Verified decimal corrections

These imported FLUX contracts use 8 decimals. Their source-list values of 18
were corrected after direct decimals() calls on 2026-11-07:

- Ethereum (1): 0x720cd16b011b987da3518fbf38c3071d4f0d1495
- Arbitrum (42161): 0x63806c056fa458c548fb416b15e358a9d685710a
- Base (8453): 0xb008bdcf9cdff9da684a190941dc3dca8c2cdd44

These corrections apply to these chain/contract identities only. Other FLUX
contracts keep their own decimals; symbols do not determine token units.

The catalog supplies candidate contracts for RPC balance checks. It is not a
wallet holdings index. Automatic scans still require a configured Multicall
deployment; catalog coverage alone does not enable a network's scanner.
